MPC Plugin SDK
--------------
The MPC build is made with the inMusic MPC Plugin Builder SDK, which is
MIT-licensed. The full MIT text is in MPC-Plugin-SDK-MIT.txt.

The drum uses the same header-only bytebeat compiler, VM and engine as Bytebeat
Machine (mpc/src/Bytebeat*.h). Those files are original work; no third-party
bytebeat player code is copied. The drum does not include QuickJS.

The built-in formula bank is shared with Bytebeat Machine. User .bb files remain
the property of their authors.
